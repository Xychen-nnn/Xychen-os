# Security Policy

## Supported versions

Security fixes are currently applied to the latest version on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do not publish exploit details in a public issue.

Report suspected vulnerabilities privately through GitHub's repository security reporting feature, if enabled. Include the affected page or endpoint, the impact, and clear reproduction steps. Do not include real passwords, private account data, or other sensitive information in a report.

This project currently has no user accounts or database-backed personal data.
